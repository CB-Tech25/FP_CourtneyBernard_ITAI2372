# AI-Based Predictive Maintenance for Space Missions

**Name:** Courtney Bernard  
**Course:** ITAI 2372  
**Project Track:** Conceptual Design Track  

## Project Description
This project explores how artificial intelligence can be used for predictive maintenance in space missions. The goal is to use machine learning to analyze spacecraft sensor data, detect early warning signs, and help prevent equipment failures before they happen.

## How to Read This Project
This project is a conceptual design, so there is no code to run. Start by reviewing the written report, then view the presentation slides for a summary of the project.

## Main Idea
The proposed AI system would use historical mission data and real-time sensor data to identify abnormal patterns in spacecraft systems. This could help astronauts and mission control respond earlier, improve safety, reduce mission risk, and support more reliable space missions.
